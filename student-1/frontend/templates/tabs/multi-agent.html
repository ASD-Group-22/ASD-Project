Release 2 Request Flow

1 · Student 1 UI The browser submits the project ID and analysis request through the Student 1 backend API.
2 · Planner + Evidence The Planner creates a plan and the Student 1 adapter retrieves project and task records through the owning backend API.
3 · Worker + Reviewer The Worker analyses the allowed evidence and the Reviewer checks the result against the plan and retrieved records.
4 · Human Review Approve, correct, partially accept or reject the result. The decision is recorded in the workflow history.
