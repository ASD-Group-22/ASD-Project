# Student 2 - Release 0 Agentic Loop Record

## PLAN
Requester listing ID, skill wanted/offered, evidence sources, model task.

## ACT
Capture candidate retrieval from Student 2 database API, optional Student 4 Skill Profile API enrichment, and Ollama request.

## OBSERVE
Capture allowed candidate IDs, model result, backend validation result, and review-model result.

## ADAPT
If output is invalid/weak, record the prompt/context/filter adjustment and rerun.

## Evidence checklist
- AI Mode screenshot showing Plan / Act / Observe / Adapt
- Validated recommendation screenshot
- AI review result
- Human Accept / Reject result
- CRUD screenshots
- Docker Compose `ps`
- Ollama/model evidence
- GitHub Actions run
- Before/after prompt evidence if adaptation occurred
