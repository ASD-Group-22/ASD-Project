Release 1 RAG Request Flow

1 · HTMX Frontend The user submits a retrieval or grounded-answer request.
2 · Student 2 Backend The backend validates the request and forwards it to the shared RAG service.
3 · Shared RAG Trusted application context is retrieved from the shared index.
4 · Grounded Response The result includes retrieved evidence, citations and confidence information.

The RAG server runs locally outside Docker. The backend reaches it through host.docker.internal:5003.
