Release 1 MCP Request Flow

1 · Frontend HTMX submits the user's request to the Student 2 backend.
2 · Backend The backend validates the request and calls the shared MCP service.
3 · MCP Tool The shared MCP server invokes a registered Student 2 tool.
4 · Evidence Verified application data is returned to the user as an HTML fragment.
